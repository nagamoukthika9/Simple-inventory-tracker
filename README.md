# Zepto Inventory Management using Excel

## Project Overview
This project focuses on managing inventory data using Microsoft Excel. The Zepto inventory dataset was used to organize product information, monitor stock levels, and identify products that require restocking.

## Tools Used
- Microsoft Excel
- IF Function
- Filters and Sorting
- Excel Tables

## Tasks Performed
1. Organized product details into an Inventory Tracker.
2. Included product name, category, stock quantity, and reorder level.
3. Used the IF function to identify stock status.
4. Created a Low-Stock Report.
5. Identified out-of-stock and low-stock products that require restocking.

## Sheets Included
- **Inventory Tracker:** Contains product details and stock status.
- **Low-Stock Report:** Displays products that need restocking.
- **Notes & Assumptions:** Contains project assumptions and explanations.

## Key Observation
A total of 3,732 product records were analyzed. The low-stock report identified 999 products requiring attention.

**Note:** The original dataset did not contain a reorder level. A working threshold of 2 units was used for stock monitoring.

## Conclusion
This project helped me understand basic inventory management, stock monitoring, Excel formulas, and identifying products that require restocking.
